# Class Feedback Platform 班级意见反馈平台
> 面向班级使用的轻量静态网页，用于班委收集同学们的建议与反馈。

## ✨ 项目介绍
本项目是一个静态网页应用，搭建透明、保护隐私的班级意见渠道。
同学们可以自由选择**匿名或者实名**提交班级相关建议，提交内容由管理员审核，审核通过后展示在**建议公示墙**，全班都可以浏览建议与跟进处理状态。
实名提交的个人联系方式仅管理员可见，公示时自动脱敏，兼顾表达自由与隐私安全。

### 🎯 核心功能
1. **意见提交表单**
    - 切换提交身份：匿名 / 实名。选择实名时自动展开联系方式输入框，匿名模式隐藏联系方式。
    - 反馈分类：作业压力、班级活动、自习纪律、班委建议、其他。
    - 提交成功提示，提交内容发送至管理员后台。

2. **建议公示墙（核心亮点）**
    - 内容**管理员审核后才会公开展示**，过滤不当言论。
    - 每条建议卡片展示：提交类型标签、分类标签、建议原文、处理状态、管理员跟进备注。
    - 状态可选：待处理 / 处理中 / 已完成。
    - 隐私保护：公示页面**永远不会展示实名同学的手机号、微信**等私人信息。

3. **管理员后台能力**
    - 接收新提交提醒；查看全部原始反馈（含实名提交者联系方式，仅管理员可见）
    - 审核：通过/驳回提交内容；编辑公示墙的状态、跟进备注
    - 支持导出所有反馈记录，方便班会汇总整理。

## 🎨 页面设计
- 响应式布局：电脑、手机、微信浏览器均可正常打开。
- UI风格：简约干净，白色卡片+浅蓝色主色调，浅灰背景。
- 单页网站：表单提交区 + 公示墙上下布局，无需页面跳转。

## 📌 使用场景
适用于班级班委收集同学们的想法、诉求与建议，解决“提意见没有回音”的问题，让每一条合理建议都公开可见、有跟进、有结果。

## 🚀 后续迭代规划
- 增加工单编号：提交建议后生成唯一编号，同学可凭编号查询进度
- 增加点赞功能，同学们可以为认同的建议点赞
- 公示墙分页，大量建议时优化浏览体验

## 📄 技术说明
前端：原生 HTML + CSS + JavaScript，纯静态页面，无框架。
后端：对接国内表单服务存储数据，无需自己搭建服务器。
